STEWART BRADLEY COMPANIES WEBSITE

Files:
- index.html: page content
- styles.css: all styling and responsive layout
- script.js: mobile navigation and automatic footer year
- assets/sbc-logo.png: transparent version prepared from the supplied color logo

BEFORE PUBLISHING:
1. In index.html, replace YOUR_FORM_ID with the Formspree form ID you want to use.
2. Confirm the email and phone number in the Contact section.
3. Update both /pier-services/ links to the final Pier Services URL if it will live somewhere else.
4. Upload all files/folders to the root of the GitHub Pages repository.
